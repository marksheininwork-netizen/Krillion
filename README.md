# Krillion — Endless Arena

An original neon survival browser game inspired by endless arena games. Not affiliated with krillion.io.

## Play
Open `index.html` locally, or publish with GitHub Pages: **Settings → Pages → Deploy from a branch → main → / (root)**.

**Desktop:** WASD or arrow keys to move; Space to dash. **Mobile:** drag the joystick; tap DASH.

Includes auto-aim and firing, escalating enemy waves, energy pickups, health, scoring, best-score saving, and restart. Zero dependencies or external assets.
